# 🚀 OrynLauncher V2

A modern, lightweight and customizable Minecraft: Java Edition launcher for Android.

OrynLauncher V2 is designed to provide a clean, smooth and modern Minecraft launching experience with a completely redesigned interface.

---

## ✨ Features

- 🎮 Minecraft: Java Edition support
- 🖤 Modern dark UI
- ⚡ Performance-focused launcher experience
- 📦 Modpack management
- 👤 Account management
- 🎨 Skin support
- 🪽 Cape support
- ⚙️ Customizable settings
- ✨ Smooth animations
- 📱 Designed specifically for Android
- 🔧 Custom launcher configuration
- 🌐 Multiple Minecraft versions

---

## 🎨 OrynLauncher V2

OrynLauncher V2 focuses on a clean and modern interface while keeping the launcher lightweight and easy to use.

The interface is designed around a dark black/grey theme with smooth animations and simple navigation.

---

## 🛠️ Technology

OrynLauncher V2 is built for Android and uses modern Android technologies to provide a responsive launcher experience.

### Core

- Android
- Kotlin / Java
- Jetpack Compose
- Material Design
- Minecraft Java Edition launcher core

---

## 📦 Modpacks

OrynLauncher V2 provides a dedicated modpack section for managing Minecraft modpacks directly from the launcher.

Users can organize and launch their installed modpacks without needing to manually manage everything.

---

## 👤 Accounts

Manage your Minecraft accounts directly from OrynLauncher.

Account management is designed to keep switching between supported accounts simple and convenient.

---

## 🎨 Skins & Capes

OrynLauncher V2 includes support for Minecraft skins and capes, allowing players to customize their in-game appearance.

---

## ⚡ Performance

OrynLauncher is designed with a focus on:

- Fast startup
- Smooth navigation
- Low UI overhead
- Efficient resource usage
- Stable Minecraft launching

Actual Minecraft performance depends on the device, Java runtime, Minecraft version, mods and settings.

---

## 📱 Android

OrynLauncher V2 is designed specifically for Android devices.

The interface is optimized for touch controls and different screen sizes.
